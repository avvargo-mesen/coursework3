# Мониторинг самолетов

## Описание
Программа собирает данные о самолетах, находящихся в воздушном пространстве выбранных 10 стран.
Данные получаем с помощью открытых API:
https://nominatim.openstreetmap.org/ - географич. координаты стран
https://opensky-network.org/ - данные о самолетах

Данные сохраняются в базу PostgreSQL.
Для работы с базой создан класс DBManager.

## Зависимости
Python 3.14+
PostgreSQL (библиотека psycopg2)
Poetry (управление зависимостями)
Requests (работа с API)
Python-dotenv (работа с переменными окружения)

## Использование

1) Клонировать репозиторий https://github.com/avvargo-mesen/coursework3.git
2) Установить зависимости
3) Настроить базу данных (ссоздать базу, применить schema.sql для создания таблиц)
4) Настроить переменные окружения (см. .env.example)
5) Запустить

## Методы класса DAManager
get_countries_and_aeroplanes_count() - возвращает список стран и количество самолетов в их воздушном пространстве
get_all_aeroplanes() - возвращает полный список всех воздушных судов
get_avg_speed() - возвращает среднюю скорость по всем самолетам
get_aeroplanes_with_higher_speed() - возвращает самолеты, скорость которых выше средней
get_aeroplanes_with_keyword(keyword) -  возвращает самолеты, в позывном которых содержится искомая подстрока
